# RIVA29 Street

## Abrir la pagina

Esta aplicación usa React y Vite. No abras `index.html` directamente desde el explorador de archivos, porque la página quedará en blanco y no cargará el catálogo.

Instala Node.js LTS desde [nodejs.org](https://nodejs.org/) si aún no lo tienes. Abre una terminal en la carpeta que contiene `package.json` y ejecuta:

```powershell
npm run dev
```

Abre en el navegador la dirección local que muestre Vite (normalmente `http://localhost:5173`). Mantén la terminal abierta mientras usas la página.
