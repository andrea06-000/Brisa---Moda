# Brisa Moda

## Abrir la pagina

Puedes abrir `index.html` directamente en el navegador; no necesitas instalar Node.js ni npm para ver esta pagina.

## Usar el servidor de desarrollo (opcional)

Para usar Vite, instala Node.js LTS desde [nodejs.org](https://nodejs.org/). npm se instala junto con Node.js. Luego cierra y vuelve a abrir VS Code, abre una terminal en la carpeta que contiene `package.json` y ejecuta:

```powershell
npm install
npm run dev
```

Abre en el navegador la direccion local que muestre Vite (normalmente `http://localhost:5173`).
